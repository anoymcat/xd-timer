# DeskTimer

一个桌面小工具，显示《英雄联盟》对局中**敌方召唤师技能**（主要是闪现）和大招的冷却。普通桌面窗口形态，可放副屏，也可放在主屏游戏之上（游戏在前台时自动禁用、不抢焦点）；数据来自游戏官方本地接口，**手动点击**触发计时。

## 功能

- 自动识别对局中的敌方英雄及其两个召唤师技能。
- **手动**点击技能图标开始计时：
  - 左键：按现在开始，自动回溯 3 秒（切出去点击的延迟）；
  - Shift + 左键：按 20 秒前开始（打完团才想起来）；
  - 计时中滚轮：每格 ±5 秒微调；右键：重置。
- **显示方式**：报点时间（技能就绪的游戏时间，如 `14:25`，与聊天报点一致，默认）或倒计时，托盘切换。计时以游戏内时钟为准。
- 冷却时间按**召唤师技能急速**计算：
  - 装备**急速靴**（明朗之靴 / 猩红之靴 / 竞技场版）自动读取并套用；
  - **星界洞悉（+18）**因官方接口读不到敌方小符文，做成**每个敌人一个眼睛图标手动开关**，点亮即联动到该敌全部技能的 CD。
- **传送**：原生传送按游戏时间（10:00 前 360s）和等级（之后 Unleashed Teleport 330→240，上单 300→210）估算 CD。
- **上单附赠传送**：2026 上单任务奖励的 Unleashed Teleport（390s，26.19）。上单没带传送时自动补一个传送按钮；`position` 读不到（如盲选）可**右键英雄头像**手动增减。
- **冷却遮罩**：计时中的图标上有随剩余时间顺时针收缩的暗色扇形，同游戏内技能冷却；报点模式下数字不动，看遮罩判断进度。
- **大招（R）计时**：头像旁自动显示每个敌人的大招按钮（托盘可关）。基础 CD 随敌方等级（6/11/16 → 1/2/3 级）估算，并**自动吃装备技能急速（Ability Haste）**。⚠️ 符文 AH 读不到会略偏长；重置/充能类大招（诺手、卡特等）计时不准，仅对固定 CD 团战大招参考。
- 普通桌面窗口：有标题栏（深蓝底、金色边框）、进任务栏、半透明（默认 80%，托盘可调，**不**点击穿透）；随对局自动显示/隐藏，系统托盘常驻。
- **紧凑布局**（默认开）：图标缩小、去掉分隔线，适合放在主屏。
- **放在主屏游戏之上**：游戏需设为无边框模式。游戏在前台且窗口与游戏同屏时，窗口自动禁用（点到也不响应、不抢焦点，外框金边变暗）；Alt-Tab 出去即可点击计时、拖动位置。
- **托盘选项**：`Always on Top`（置顶）、`Lock while game focused`（游戏前台自动禁用）、`Ultimate (R) Timer`（大招计时开关）、`Compact layout`（紧凑布局）、`Pin position`（锁定位置）、`Display`（报点时间 / 倒计时）、`Opacity`（不透明度 60–100%）、`Scale`（缩放 50–200%）、`Quit`。图标资源过期时托盘顶部会提示重跑 `download_assets.py`。
- 高清渲染（DPI 感知）+ 海克斯金色边框。

## 数据来源

仅使用游戏官方本地 **Live Client Data API**（`https://127.0.0.1:2999`）。
**不**读取游戏内存、**不**注入、**不**挂钩键盘、**不**截屏、**不**向游戏发送任何输入。

## 运行（Windows）

```cmd
setup.bat                    :: 创建虚拟环境并安装依赖
python download_assets.py    :: 下载英雄/技能图标（只补缺失；--force 全量重下）
```

然后任选其一启动：

- 双击桌面快捷方式 **DeskTimer**
- 运行 `start.bat`
- `python main.py`

> 跑源码，不打包 exe。计时核心单元测试：`python -m unittest discover -s tests`。开发细节见 [`CLAUDE.md`](CLAUDE.md)。

## 便携版（无需安装 Python）

在已装好环境的机器上运行 `python make_portable.py`，会生成 `DeskTimer_portable.zip`：内含一份独立的官方 Python（自带 tkinter）+ 依赖 + 源码 + 图标。拷到**没装 Python 的电脑**上解压后：

- 双击 **`DeskTimer.vbs`** 即运行（无黑窗）；
- 想要桌面图标：双击一次 **`创建桌面快捷方式.vbs`**。

> 便携版跑的仍是官方 `python.exe` + `.py` 源码，**非 PyInstaller 编译 exe**。首次启动可能被 SmartScreen/杀软误报，自行判断放行。
