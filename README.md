# DeskTimer

一个跑在副屏的桌面小工具，显示《英雄联盟》对局中**敌方召唤师技能**（主要是闪现）的冷却倒计时。普通桌面窗口形态，数据来自游戏官方本地接口，**手动点击**触发计时。

## 功能

- 自动识别对局中的敌方英雄及其两个召唤师技能。
- **手动**点击技能图标开始冷却倒计时：左键计时、右键重置。
- 冷却时间按**召唤师技能急速**计算（仅识别装备靴子的急速）。
- 普通桌面窗口：有标题栏、进任务栏、不置顶，可拖到副屏；随对局自动显示/隐藏，系统托盘常驻。

## 数据来源

仅使用游戏官方本地 **Live Client Data API**（`https://127.0.0.1:2999`）。
**不**读取游戏内存、**不**注入、**不**挂钩键盘、**不**截屏、**不**向游戏发送任何输入。

## 运行（Windows）

```cmd
setup.bat                    :: 创建虚拟环境并安装依赖
python download_assets.py    :: 下载英雄/技能图标
```

然后任选其一启动：

- 双击桌面快捷方式 **DeskTimer**
- 运行 `start.bat`
- `python main.py`
