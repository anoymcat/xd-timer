# DeskTimer

一个跑在副屏的桌面小工具，显示《英雄联盟》对局中**敌方召唤师技能**（主要是闪现）的冷却倒计时。普通桌面窗口形态，数据来自游戏官方本地接口，**手动点击**触发计时。

## 功能

- 自动识别对局中的敌方英雄及其两个召唤师技能。
- **手动**点击技能图标开始冷却倒计时：左键计时、右键重置。
- 冷却时间按**召唤师技能急速**计算：
  - 装备**急速靴**（明朗之靴 / 猩红之靴 / 竞技场版）自动读取并套用；
  - **星界洞悉（+18）**因官方接口读不到敌方小符文，做成**每个敌人一个眼睛图标手动开关**，点亮即联动到该敌全部技能的 CD。
- **上单附赠传送**：2026 上单任务奖励的 Unleashed Teleport（420s）。上单没带传送时自动补一个传送按钮；`position` 读不到（如盲选）可**右键英雄头像**手动增减。
- 普通桌面窗口：有标题栏、进任务栏，可拖到副屏；随对局自动显示/隐藏，系统托盘常驻。
- **托盘选项**：`Always on Top`（置顶开关，默认开）、`Scale`（界面缩放 50–200%）、`Quit`。
- 高清渲染（DPI 感知）+ 海克斯金色边框。

## 数据来源

仅使用游戏官方本地 **Live Client Data API**（`https://127.0.0.1:2999`）。
**不**读取游戏内存、**不**注入、**不**挂钩键盘、**不**截屏、**不**向游戏发送任何输入。

## 运行（Windows）

```cmd
setup.bat                    :: 创建虚拟环境并安装依赖
python download_assets.py    :: 下载英雄/技能图标
```

然后任选其一启动：

- 双击桌面快捷方式 **DeskTimer**
- 运行 `start.bat`
- `python main.py`

> 跑源码，不打包 exe。开发细节见 [`CLAUDE.md`](CLAUDE.md)。

## 便携版（无需安装 Python）

在已装好环境的机器上运行 `python make_portable.py`，会生成 `DeskTimer_portable.zip`：内含一份独立的官方 Python（自带 tkinter）+ 依赖 + 源码 + 图标。拷到**没装 Python 的电脑**上解压后：

- 双击 **`DeskTimer.vbs`** 即运行（无黑窗）；
- 想要桌面图标：双击一次 **`创建桌面快捷方式.vbs`**。

> 便携版跑的仍是官方 `python.exe` + `.py` 源码，**非 PyInstaller 编译 exe**。首次启动可能被 SmartScreen/杀软误报，自行判断放行。
